# Smart Classroom Edge AI System

## Project Overview

This project implements an Edge AI based Smart Classroom system that detects classroom occupancy levels from video footage and automatically controls a simulated air conditioning system.

## Objectives

- Detect LOW, MEDIUM and HIGH occupancy levels
- Run AI inference on an edge device
- Simulate automated AC control
- Display system status using a dashboard
- Demonstrate simple MLOps practices
